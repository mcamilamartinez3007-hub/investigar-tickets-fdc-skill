How to edit this file

Everything is in the DATA BLOCK at the top of the file, between the two banner comments. Open it in any text editor. There are no coordinates: positions, arrows and text wrapping are computed from lane and col.

Add a step: insert an object into a phase's path array, in flow order. Give it a free col and the lane id of the system where its work lands. Raise cols if you run out. Arrows are drawn automatically.

Make a step wider: add span:2 (or more). It then occupies that many columns, so the next step needs a col that far along.

Mark a step as affected: add changed:true. It gets a red outline and a red corner tab. Add pending:true as well when the object or rule is not defined yet — the outline turns dashed.

Label an arrow: add next:"..." to the step it leaves from.

Add a tab: append an object to views with its own tab, lanes, phases, legend and notes.

Add sub-tasks: give the step shape:"proc" and a subprocess object. It becomes clickable.

{ id:"n23", lane:"snow", col:9, kind:"flow", shape:"proc", badge:"23",
  title:"ACCORDIA_FDC_DOWNTIME_ORCHESTRATOR_MERGE", sub:AIRFLOW,
  subprocess: {   // or: subprocess: SP_ORCH  (shared, defined once at the top)
    title:"ACCORDIA_FDC_DOWNTIME_ORCHESTRATOR_MERGE",
    note:"One sentence on what this orchestrator does.",
    steps: [
      { n:"1", kind:"task",  title:"Stage the Historian output",
        detail:"Reads <code>dev_v_dataexport_downtime_to_fdc</code> into the merge input." },
      { n:"2", kind:"check", title:"Row-count guard",
        detail:"Stops the merge if the input is empty." },
      { n:"3", kind:"fail",  title:"Raise and notify",
        detail:"Routes to the shared Send notification task." }
    ]
  }
}

kind sets the colour: term, mile, wait, flow, store, gate, fail.
shape sets the outline: box, term, dia, cyl, trap, proc, delay.
Sub-task kind: task, check, fail. Mark a notes card warn:true for a red left border.

Self-contained: no internet, no libraries, no build step.
