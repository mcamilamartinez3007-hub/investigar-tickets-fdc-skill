# Source material

This directory stores original technical evidence incorporated into the repository.

## Rules

- Preserve each file without modification.
- Organize it by domain and, when useful, by ticket.
- Do not store credentials, tokens, unnecessary PII, or private links.
- Record provenance, date, environment, and commit.
- Keep interpretations and conclusions in references/, not here.
- Update references/source-material-manifest.md when adding content.

Technical files discussed before version 1.0.0 still need to be incorporated. Their absence must remain visible and must never be replaced with reconstructed content.
